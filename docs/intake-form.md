# Intake form (Zoho Forms)

Form name: **Client Onboarding Intake**

| Field | Type | Required | Notes |
|---|---|---|---|
| Name | Name (First, Last) | Yes | Both parts required |
| Email | Email | Yes | Used as the CRM match key |
| Phone | Phone | Yes | |
| Company Name | Single line | Yes | Names the Projects task list and the PDF |
| Website | Website | No | |
| Service Package | Dropdown | Yes | Starter, Growth, Enterprise |
| Preferred Start Date | Date (dd-MMM-yyyy) | Yes | Shown as kickoff date in the welcome pack |
| Project Goals | Multi line | Yes | Quoted in the welcome pack |

## Why standardize first

Automation is only as reliable as its input. Free-form emails produce inconsistent data, so every later step would need manual checking. A fixed form with required fields and a fixed package list means every downstream step can trust the data it receives.
