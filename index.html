The problem

Every new client meant the same three hours of admin

Before
  1. Collect details over email and calls, in a different format each time
  2. Re-type the client into the CRM
  3. Copy last client's welcome doc, edit names and dates by hand
  4. Export to PDF and email it
  5. Create the project tasks from memory
  6. Chase whatever was missing from the intake
After
  1. Client fills in one standard intake form
  2. Everything else happens automatically, in about 3 seconds

No re-typing, no copy-paste errors, and no forgotten steps. Every client gets the same quality of onboarding.

Step one · Standardize intake

Automation only works when the input is predictable

Before automating anything, I replaced free-form emails with a single intake form. Required fields stop onboarding from starting with gaps, and the service package is a fixed list so every downstream step can rely on it.

Name *first + last
Email *CRM match key
Phone *CRM contact
Company name *names the task list
Websiteoptional
Service package *Starter · Growth · Enterprise
Preferred start date *dd-MMM-yyyy
Project goals *quoted in welcome pack
